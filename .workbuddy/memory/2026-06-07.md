# 2026-06-07 工作日志

## Web端用户管理菜单不显示修复
- **问题**：管理员登录后，顶部 Tab 没有"用户管理"菜单
- **根因**：`isAdmin` computed 直接读 `Auth.getUserInfo()`（同步读 localStorage），但 Vue computed 不会感知 localStorage 变化；且老用户登录时 localStorage 根本没有 `user_info`
- **修复**：
  - `WebLayout.vue`：`isAdmin` 改为基于 `ref(userRole)` 的 computed；新增 `ensureUserInfo()` 在挂载时检查——如果有 token 但没有 user_info，主动调 `/user/profile` 获取并写入 localStorage；监听 `storage` 事件（跨 Tab）和自定义 `user-info-updated` 事件（同 Tab）
  - `Login.vue`：登录成功后 `Auth.setUserInfo()` 保存用户信息，并 `window.dispatchEvent(new Event('user-info-updated'))` 通知 WebLayout 刷新
  - `api.js`：`logout()` 和 401 跳转时也 dispatch `user-info-updated` 事件；401 时同时清除 `user_info`
- **编译**：`go build ./web/...` ✅

## Web端未登录API 401问题修复
- **问题**：未登录时前端组件直接调用后端API，导致401；401跳转使用 `window.location.href='/login'` 在 hash 模式下不正确
- **修复**：
  1. **router.js**：添加 `/login` `/register` 路由（meta: { public: true }）；添加 `beforeEach` 守卫——桌面端跳过，Web端未登录跳 `/login`（带 redirect 参数）
  2. **api.js**：401 跳转从 `window.location.href='/login'` 改为 `window.location.hash='#/login'`（hash 模式）；加防抖标记防止并发请求重复跳转
  3. **App.vue**：
     - `onBeforeMount`/`onMounted` 中 Web 模式跳过 wailsjs 原生调用（`GetVersionInfo`/`GetGroupList`/`GetConfig`）
     - `FloatingAgentAssistant` 加 `v-if="!isWebMode"`（Web 端有独立 agent 页面，该组件依赖 wailsjs）
     - 新增 `isAuthPage` computed（login/register 页面不显示 WebLayout 导航）
     - Web 模式下 auth 页面直接渲染 `<RouterView/>` 无导航
  4. **Login.vue**：登录后 redirect 改从 `router.currentRoute.value.query.redirect` 获取（路由守卫带过来的）
  5. **Register.vue**：注册成功后也调用 `Auth.setUserInfo()` 保存用户信息
- **编译**：`go build ./web/...` ✅

## 未登录页面加载问题修复（第二轮）
- **问题**：Web模式下未登录时，组件仍然加载并发起API请求，闪现页面内容
- **根因**：
  1. `Auth.isLoggedIn()` 只检查 token 存在性，不验证有效性（过期 token 被当作已登录）
  2. `stock.vue` 直接从 `wailsjs/go/main/App` 导入，Web模式下调用崩溃
  3. `FloatingAiAssistant/FloatingAgentAssistant` 在登录页也渲染，发起无效请求
- **修复**：
  1. **router.js**：路由守卫改为 `async`，token 存在但无 user_info 时调 `/user/profile` 验证有效性，无效则清除 token 并跳转登录
  2. **App.vue**：`FloatingAiAssistant` 和 `FloatingAgentAssistant` 添加 `v-if="!isWebMode"`
  3. **stock.vue**：引入 `useIsWebMode` + `Bridge`（wails-bridge.js），`onBeforeMount`/`onMounted` 用 `isWebMode` 分发——Web端用 Bridge HTTP API，桌面端用 Wails 原生绑定
- **编译**：`vite build` ✅
