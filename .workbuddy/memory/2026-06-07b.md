- **修改点**：

## 提示词模板错误提示优化（追加）
- **问题**：添加重复名称模板时返回 409 + `{"error":"Template name already exists","message":"模板名称已存在"}`，前端显示 "Request failed with status code 409"
- **修复**：
  1. `wails-bridge.js`：`AddPromptTemplate`/`UpdatePromptTemplate` catch 中从 `err.response.data` 提取中文 message 并 throw
  2. `promptTemplateList.vue`：`savePromptTemplate` 加 `.catch()` 友好提示（名称重复→"该模板名称已存在，请更换名称后重试"；未找到→"模板不存在"；通用→"保存/添加失败"）；成功提示 `message.info` → `message.success`
  3. `prompt_handler.go`：409 响应体改为 `{"code":1, "message":"该模板名称已存在，请更换名称后重试"}`，去掉 `error` 字段
  4. `DeletePromptTemplate` 也加了 `.catch()` 处理
- **根因**：`promptTemplateList.vue` 在 Web 模式下仍直接 import Wails 函数，未走 `wails-bridge.js`，导致：
  - Web 端调的是空壳函数而非后端API，409 等错误无法被 axios 正确解析
- **修复**：`promptTemplateList.vue` 引入 `isWebMode` + bridge 函数，所有 API 调用根据模式分发
  - `GetConfig` → `GetConfigBridge`（onBeforeMount、showShareModal）
  - `GetPromptTemplateList` → `GetPromptTemplateListBridge`（query函数）
  - `AddPromptTemplate` → `AddPromptTemplateBridge`（savePromptTemplate）
  - `UpdatePromptTemplate` → `UpdatePromptTemplateBridge`（savePromptTemplate）
  - `DeletePromptTemplate` → `DeletePromptTemplateBridge`（deletePromptTemplate）
- `wails-bridge.js`：`DeletePromptTemplate` 也改为 throw Error 模式（与 Add/Update 一致）

## 提示词类型(type)与广场分类(category)对齐（追加）
- **问题**：从广场"添加到我的模板"时 `type` 硬编码 `'模型系统Prompt'`，与广场实际 `category` 不一致
- **广场 category**：模型系统Prompt、模型用户Prompt、A股筛选、数据分析、择时选股
- **本地 type 原来只有**：模型系统Prompt、模型用户Prompt
- **修复**：
  1. `promptPlaza.vue` 的 `addPromptToTemplate`：直接取 `prompt.category` 作为 `type`，不再做映射转换（用户要求原值保留）
  2. `promptTemplateList.vue` 的 `promptTypeOptions`：增加 A股筛选、数据分析、择时选股 三个选项
