- `StockLightweightKlineChart.vue:3800` 位置参数调用 `createDrawingHost(chart, candleSeries, container)`，

- 其他页面（自选/交易记录等）靠 `watch(props.code)` 二次触发 loadData 所以"看起来正常"；
  重大指数的 code 是硬编码常量，初始加载丢了就永远空。
- 引入批次：`b316fdb`（2026-08-02 绘图原语移植）。桌面端同样受影响（同一段代码）。

**修复**：`createDrawingHost({ chart, series: candleSeries, container: chartContainerRef.value })`（1 行）。
已 rebuild 前端并替换 `frontend/dist`（旧 dist 备份在 `.diag/dist-backup/`），playwright 实测：初始 klt=101 请求自动发出、上证指数日K完整渲染。

## 重大指数海外指数（恒生/道琼斯/标普/纳斯达克）空白修复（20:45）
- 根因：重大指数用东财 secid `100.HSI/100.DJIA/100.SPX/100.NDX`，降级链为 MAC(守卫直接空)→东财；本机 `push2his.eastmoney.com` 被墙（EOF），而代码注释断言「新浪/腾讯/通达信均不支持海外指数」直接返回空。
- **该注释是错的**：实测腾讯 `web.ifzq.gtimg.cn` 完全支持——hkHSI/usDJI/usINX/usNDX；且美股指数必须走 `usfqkline/get` 端点（fqkline 只给最近1根），usfqkline 行内第7列是 `{}` 对象需替换为 "0" 才能 [][]string 反序列化。新浪 CN_MarketDataService 确实不支持（返回 null）。
- 修复（均在 backend/data/sina_kline_api.go）：① tencentSymbolFromStockCode 加 100.XXX→hkHSI/usDJI/usINX/usNDX 映射；② FetchKLineWithFallback 海外指数分支东财失败后加腾讯降级；③ GetKLineData 美股指数切 usfqkline 端点 + 清洗 {}；④ 修正 tool_eastmoney_kline.go 过时注释。
- 验证：go test 四指数全 tencent 10条；8081 临时实例 playwright 实测四标签全渲染；运行日志见完整降级链 MAC空→东财EOF→腾讯→200。
