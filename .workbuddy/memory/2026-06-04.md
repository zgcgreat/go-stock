# 2026-06-04 工作日志

## Web端 AI助手排版修复

### 问题分析
Web端 `agent-chat.vue`（桌面端 Agent 聊天组件）AI 输出排版混乱，根因：
1. **CSS选择器不匹配**：`agent-chat.vue` 使用 `<t-chat-content>` 渲染 Markdown（内部用 `marked` 库，渲染到 `.t-chat__text__content`），但 `style.css` 中 e07e198 和 acd3406 两次提交新增的约200行 Markdown 增强样式全部写给 `.md-editor-preview` 选择器，对 agent-chat 完全无效
2. **`formatMarkdown` 中 `splitInlineHeading` 破坏 `---##` 格式**：AI 输出 `---##标题` 被错误拆分，ai-assistant-web/App.vue 已修复但 agent-chat.vue 未同步
3. **`marked` 与 `md-editor-v3` 渲染能力差异**：`t-chat-content` 的 `marked` 不支持数学公式、GFM扩展等

### 修复方案（方案A）
将 `agent-chat.vue` 中3处 `<t-chat-content>` 替换为 `<MdPreview>`，与 FloatingAgentAssistant.vue 和 ai-assistant-web/App.vue 保持一致：
- 导入 `MdPreview`、`md-editor-v3/lib/preview.css`、`codeBlockEnhancer.js`
- 替换模板中 reasoning/jsonMarkdown/content 3处 `t-chat-content`
- 同步 `formatMarkdown` 中 `hrHeadingMatch`/`hrBlockMatch` 修复
- 同步 `splitInlineHeading` 中 `hrMatch` 修复
- 新增 `darkThemeRef`/`mdTheme`/`codeTheme`/`onMdHtmlChanged`
- 新增 MdPreview 样式穿透和代码块增强样式
