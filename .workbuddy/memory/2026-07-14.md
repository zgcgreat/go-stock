
## Web/桌面端功能一致性对比（只读分析）
- 前端所有 Go 调用统一走 frontend/src/services/wails-bridge.js（264 个导出函数，isWailsMode() 分支：Wails→window.go.main.App.X，Web→/api/v1 HTTP API）；组件不直接调 window.go。
- server.go 路由共 209 条（~196 protected + auth/admin）。
- 发现 Web 端断点：
  1) bridge 调用但 server 无路由：/manual (GetUserManual→静默'')、/feishu/message (SendFeishuMessageByType→"发送失败")、/user-profile/relearn (RelearnUserProfile)。
  2) Web 端空数据 stub：GetDailyDimensionStats→[]（AnalyzeMartket.vue 1254 行调用）、GetTypeStatsByDate→[]。
  3) KB 功能 Web 不支持：UploadKBFiles/PickKBFilePaths → {code:1, 'Web端暂不支持文件上传/选择'}（knowledge-base-manager.vue）。
  4) Web stub：CheckUpdate→{hasUpdate:false}、GetVersionInfo→{version:'web'}、HideToTray/ShowFromTray/RestartAsAdmin→console.warn。
  5) 桌面独有且前端无消费入口：StartFeishuBot/StopFeishuBot/GetFeishuBotStatus、GetHistoryTdxMinuteTimeData/GetHistoryTdxTransactionData/RefreshAllTdxTransactionData（Web 只有 /tdx/minute /tdx/transactions 实时数据）、GetMarketEmotion/GetIndexQuotes/GetChipDistribution/GetSectorAnchors/GetTdxCallAuction/GetIndexTline/GetStockCommonKLine（前端无任何组件使用，疑似死代码或仅内部用）。

- VIP：Web 端 GetEffectiveSponsorVip 读 /user/profile role（admin→VIP2），不依赖赞助码。
