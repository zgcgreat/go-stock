# 2026-06-09 工作记录

- 修复手机端研究页二级菜单点不到且无法滑动的问题：根因是 NaiveUI `n-tabs` 内部使用 `VXScroll`（vueuc 虚拟滚动组件）控制水平滚动，其 `::before`/`::after` 伪元素做阴影遮罩会遮挡边缘 Tab 点击，同时 `.n-tabs-scroll-padding` 占据两侧空间挤压 Tab 区域。修复方式：`style.css` 全局移动端隐藏 `.n-tabs-nav-scroll-wrapper::before/::after` 阴影遮罩和 `.n-tabs-scroll-padding` 空白，VXScroll 容器加 `-webkit-overflow-scrolling: touch`；同步更新 `researchIndex.vue`、`market.vue`、`fund.vue` 的 scoped 样式。验证 `npm --prefix frontend run build` 和 `git diff --check` 通过。

- 分析股市行情全部 Tab 层级：发现 `type="segment"` 的 Tab（全球股指8项、重大指数19项）与 line/card 使用完全不同的 DOM 结构（tabs-rail 容器而非 VXScroll），全局CSS覆盖不生效。segment 用 `flex-basis:0 + flex-grow:1` 均分宽度，19个Tab被极度压缩不可读。
- 修复 segment 类型 Tab 移动端横向滚动：`style.css` 新增 `.n-tabs--segment-type .n-tabs-rail` 改为 `width:max-content + overflow-x:auto`，`.n-tabs-tab-wrapper` 改为 `flex-basis:auto + flex-grow:0`。提交 `4b9bfe4`。
- 合并上游 dev 分支（1个新提交：板块资金流向功能增强），解决 bkFundFlowChart.vue 的 import 冲突，适配 wails-bridge.js（GetAllBKCodes/GetBKFundFlowList/GetBKFundFlowTopList），新增 Web handler 和路由。提交 `b2cd563`。
- 检查钉钉通知功能：发现 `dingding_api.go` 的 `SendDingDingMessage()` 和 `getApiURL()` 都使用 `GetSettingConfig()`（始终读 user_id=0 的配置），Web 端多用户场景下会读取错误用户的配置。Web handler `SendDingDingMessage()` 也调用 `data.NewDingDingAPI().SendToDingDing()` 走同一全局配置。`wails-bridge.js` 的 `SendDingDingMessageByType` Web fallback 只返回 `'发送成功'` 没有实际发送。
