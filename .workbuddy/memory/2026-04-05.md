## 全球股指数据展示修复（2026-04-05 晚上）
问题：market.vue 和 AnalyzeMartket.vue 中全球股指（上证指数等）数据展示不正确
根因：腾讯 API 返回的 zdf（涨跌幅）、zxj（最新价）是字符串类型（如 "-1.00"、"3880.10"），
      n-number-animation 的 :to prop 期望 Number 类型，传入字符串导致数字动画显示异常
修复：
1. ✅ AnalyzeMartket.vue 添加 normalizeIndexData() 函数，将 zdf/zxj 从字符串转为 parseFloat
2. ✅ market.vue 添加 normalizeIndexData() 函数，同样处理数据类型转换
3. ✅ 前端构建验证通过

## K 线接口返回格式修复（2026-04-05 晚上）
问题：Web 端 K 线页面无数据（/api/v1/stocks/:code/kline）
根因：后端 handler 返回 {"code":0,"data":{"code":"sh000001","name":"上证指数","klt":"101","kline":[...]}},
      但前端 KLineChart.vue 和 stock.vue 期望 data 直接是 KLineData 数组（result[i].day 等），
      与 Wails 桌面模式返回 *[]KLineData 一致。extractApiData 取出 data 后得到的是对象而非数组，
      result.length 为 undefined 导致循环不执行
修复：handler 的 data 直接返回 kLines 数组，删除无用的 stockName 查询
