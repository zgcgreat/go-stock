# 2026-06-06 工作日志

## Web 端 Agent Chat 配置查询用户隔离修复
- **问题**：`AgentChat` handler 和 `AITradeAnalyze` handler 调用 `agent.ChatWithContext` 时，Agent 内部用 `GetSettingConfig()` 查询的是 `user_id=0` 的全局配置，导致 Web 端登录用户查不到自己的 AI 配置
- **修复**：
  - `agent_api.go`：`ChatWithContext` 和 `newStockAiAgent` 签名保持不变（桌面端不受影响），通过 `optsOverride[2]` 传递 `userID` 字符串
  - `newStockAiAgent`：从 `optsOverride[2]` 解析 userID，`userID>0` 时用 `GetSettingConfigByUserID(userID)` 查配置，`userID=0` 时用 `GetSettingConfig()`（桌面端行为不变）
  - `ChatWithContext` 中第二个 `GetSettingConfig` 调用也改为同样的逻辑
  - `ai_handler.go`：`AgentChat` 和 `AITradeAnalyze` 都在调用 `ChatWithContext` 时传入 `"", "", userIDStr"` 作为 optsOverride
  - 新增 `strconv` import
- **编译**：`go build ./web/...` ✅
